\section{Decision theoretic argument for glm-type estimator/estimand}


Consider a following model: we have $(Y, X, W)$ distribution. Assume unconfoundedness $Y(w) \perp W | X$. The potential outcomes $Y(W)$ are parametrized with $\theta$. Define a function $\mu_\theta: W \to \mathbb{R}$ as $\mu_\theta(w) = \mathbb{E}[Y_\theta(w)]$  Consider a decision problem with a loss function of the following form: $l(\mu_\theta, a)$. We maximize $l$. For now $W$ is abstract and can be $\{0, 1\}$ or anything.

Now, when we solve this, we get a solution $a^\ast$ that is a function of $\mu_\theta(.)$.  The question is only, what kind of problems lead to this kind of loss function. Can we think of it axiomatically?

Further, if the problem is anti symmetric, meanin that $l(\mu_\theta, a)$ is anti symmetric in $W$ (switching $W=0$ to $1$ and $a$ to $-a$ doesn't change the solution/parameter of interest), we can write

\[f(g(\mathbb{E}[Y_i(1)]) - g(\mathbb{E}[Y_i(0)]))\]

This is like constant causal contrast, but instead, we have a function applied after E. So adding something to all Y wouldn't help. But here we instead add something after applying a function $g$. 

So, level irrelevance would be as follows:

suppose there exists some function $g$ such that redefining $g(\mu) = g(\mu + 1)$ doesn't change the solution. Then, we are dealing with this glm setting.

Can we interpret level irrelevance property? Like for poisson regression this would exactly be the percentage property. And it will be in a lot way better then that log thing.
